> Одинаковый инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert потенциально опасными или относящимися к хакерским инструментам. В результате файл удаляется и переносится в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). В Kaspersky, например, используется параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы точно понимаете настройку исключений, предпочтительно добавить исключение; при сомнениях рекомендуется отключить обнаружение PUA.

## ⚙️Установка и использование

1. Сначала активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличный от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, подойдет `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При распаковке через 7-Zip или PeaZip этот пункт можно не выполнять

4. Распакуйте архив в каталог, путь к которому не содержит кириллических букв и специальных символов

5. Запустите нужный скрипт
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, перейдите в **`service.bat`** -> `Install Service` и выберите подходящую стратегию

## ℹ️Назначение файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдете подходящий для себя**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удалить стратегию и WinDivert из списка служб
  - **`Check Status`** - посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменить режим обхода для игр и других сервисов, работающих по UDP и TCP через порты выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Состояние функции отображается в скобках: включено или выключено.
  - **`IPSet Filter`** - изменить режим обхода ресурсов из `ipset-all.txt`.  
  Это помогает при проверке ресурса, который без zapret доступен, а с ним не открывается.  
  В скобках показывается текущий режим:
    - `none` - ни один IP не участвует в проверке
    - `loaded` - проверяются IP, присутствующие в списке
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** - заменить текущий используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** - получить актуальную версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** - вручную проверить наличие обновлений
  - **`Run Diagnostics`** - проверить распространенные причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работу приложения после внезапного сбоя
  - **`Run Tests`** - открыть инструмент проверки стратегий:
    - `Standard tests` - проверить сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` - проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не появляется

- При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe (обход). Его можно увидеть на панели задач.  
Если winws.exe не появился, обратитесь к [#522](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/522)

### Подходящей стратегии нет
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезапустите компьютер

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота
  - Найдите файл `hosts` в созданной папке и откройте его текстовым редактором от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный блок
  - Сохраните файл и проверьте подключение еще раз. Если результата нет, убедитесь, что изменения действительно были сохранены.

#### Работа не гарантируется. При отсутствии результата используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/Featherdrodepot89/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не гарантируют постоянную работу.**
> После обнаружения определенная стратегия может перестать работать, даже если некоторое время она давала результат.
> В репозитории собраны разные варианты обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из них и измените ее параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не показывает ошибок

- Проверьте, добавлен ли адрес ресурса в список доменов или IP-адресов

- Переключитесь на другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация находится в [#765](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/765)

### Как выполнить полную переустановку или обновление?
- Сохраните ресурсы и данные, которые добавляли самостоятельно
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Выполните `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию [со страницы релизов](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если в нижней части окна доступен флажок разблокировки, включите его, нажмите "Применить", затем "ОК"
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если очередная стратегия не подходит, закройте программу через значок замка на панели задач и выберите следующую
- Найдя рабочую стратегию, включите ее автозапуск через `service.bat` -> `Install Service`

### Игра или приложение не работает при включенном zapret

- Проверьте в service.bat, что `Game Filter` имеет статус **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкции доступны [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide)

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите ее следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям
- Переберите остальные стратегии, особенно если прежняя недавно перестала работать
- См. также [#251](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Сначала проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Определите, на какой стратегии открывается YouTube, и запустите ее для проверки Discord
- В `service.bat` перейдите в `Run Diagnostics` и выполните очистку кэша Discord
- Проверьте, помогла ли очистка приложению Discord
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ею
- Если браузерная версия тоже недоступна, повторно проверьте все стратегии: одна может открывать YouTube, но не Discord
- См. также [#252](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Featherdrodepot89/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не подключаются

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно помогает следующий порядок действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включенным постоянно: определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions), а не issue, и дождитесь ответов других игроков.

### Решения для моей проблемы нет

- Опишите проблему [в разделе issues](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Списки обхода можно дополнить собственными адресами:
- **`list-general-user.txt`** предназначен для доменов; поддомены учитываются автоматически
- **`list-exclude-user.txt`** исключает домены, например когда IP сети уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** содержит IP-адреса и подсети
- **`ipset-exclude-user.txt`** используется для исключения IP-адресов и подсетей
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
