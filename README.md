> ### АНТИВИРУСНОЕ ПО
>
> В составе zapret используется WinDivert, который способен вызвать срабатывание антивируса.  
> Это средство перехватывает и фильтрует сетевой трафик и необходимо для работы zapret.
> WinDivert может применяться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В таком случае файл удаляется и перемещается в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительно добавить исключение. В противном случае рекомендуется отключить детектирование PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox включите "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`: провайдер Cloudflare может оказаться заблокирован.
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, это действие не требуется.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Чтобы подобрать рабочую стратегию, откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для установки стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вашей сети**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** устанавливает выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние (включено или выключено) указано в скобках.
  - **`IPSet Filter`** переключает обработку сервисов, перечисленных в `ipset-all.txt`.  
  Это пригодится при диагностике ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках отображается один из режимов:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - проверяется наличие IP-адреса в списке
    - `any` - под фильтр попадает любой IP-адрес  
  - **`Auto-Update Check`** включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** заменяет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** загружает актуальную версию `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и соединения с голосовым чатом Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В конце диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает, если приложение внезапно перестало работать.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` тестирует сайты из `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если процесс не запустился, обратитесь к [#522](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/522).

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора.
  - Вставьте скопированный текст в конец файла `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. При отсутствии результата используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Featherdrodepot89/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время работал, может перестать работать после его обнаружения.
> В репозитории собрано много стратегий обхода. Если готовые варианты не помогают, создайте собственную на основе одной из них и измените параметры.
> Описание параметров доступно [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результат `service.bat` -> `Run Diagnostics` и исправьте найденные ошибки.

- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов.

- Переключитесь на другие стратегии, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?
- Сохраните ресурсы и данные, которые добавляли вручную.
- Перезапустите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок устраните их, затем в конце выберите Y.
- Удалите старый каталог zapret.
- Скачайте новую версию `zapret-discord-youtube-...` [со страницы релизов](https://github.com/Featherdro depot89/zapret-discord-youtube/releases).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить", затем "ОК".
- Распакуйте файлы в новый каталог в корне диска, без пробелов и специальных символов.
- Запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если выбранный вариант не помогает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочего варианта установите его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Найдите имя службы в командной строке Windows, открытой через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше выбранный вариант работал.
- См. также [#251](https://github.com/Featherdro depot89/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8F-использование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- Через `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/Featherdro depot89/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую из них отдельно невозможно.

Попробуйте универсальную последовательность:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если это не помогло, дополнительно включите `ipset any`.

Учтите, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если результата по-прежнему нет, создайте обсуждение в разделе [Discussions](https://github.com/Featherdro depot89/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Создайте обращение [здесь](https://github.com/Featherdro depot89/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Список ресурсов для обхода расширяется через следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены, которые нужно исключить. Это полезно, например, когда IP-сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети для исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
